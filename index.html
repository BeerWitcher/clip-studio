GTA Clip Studio

A private editing tool for gaming Shorts

GTA Clip Studio is a self-hosted tool used by Yaroslav to turn highlights of public gameplay streams into short vertical videos for the operator’s own YouTube channels.

How it works

  • Find moments — detects highlights from chat reactions, “most replayed” data and audio peaks.
  • Edit — cuts 15–60 second clips, converts them to 9:16, adds captions, a title and an on-screen credit to the original creator.
  • Publish — uploads the finished clips to channels the operator owns, via the YouTube Data API (videos.insert), with credit and a link to the source stream in every description.

Google account access

The App requests only the youtube.upload permission, used solely to upload videos to the authorized channel. Read the Privacy Policy for details, and revoke access any time at Google security settings. Uploading through the App means agreeing to the YouTube Terms of Service.
